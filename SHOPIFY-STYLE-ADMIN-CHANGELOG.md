# Aniverse Shopify-style admin upgrade

This release reorganizes the admin around familiar ecommerce back-office workflows: Home, Orders, Draft Orders, Products, Inventory, Collections, Customers, Analytics, Discounts, Content & Files, Shipping, Staff & Permissions, and Settings.

Key additions:
- global admin search
- product bulk actions + CSV export
- product media/SKU/vendor/tags/weight fields
- inventory adjustment history
- collection management with multi-collection products
- order filters, notes/tags, customer/shipping editing, refunds and Shiprocket actions
- draft order creation
- customer order count and paid spend
- analytics dashboard
- discount codes and storefront checkout validation
- media library
- shipping/store settings
- staff account management
- admin activity log
- public store settings endpoint for shipping thresholds/rates
- smoke test can start the local server automatically

This is an original Aniverse implementation inspired by common ecommerce admin workflows; it does not copy Shopify source code or branding.
