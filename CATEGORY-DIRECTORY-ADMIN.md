# Category Directory + Admin Control

The customer-facing **All Categories** page now starts with the same merchandise categories exposed in the navigation:

- Figurines
- Premium Figures
- Keychains
- Katanas
- Anime Lamps
- Merchandise
- Miniature Sets
- Funko Pop
- Qposket
- DIY Blocks
- Banpresto

Anime/world collections are kept out of this directory and remain controlled through **Admin → Anime Hero**.

The initial merchandise categories are seeded **once**. After that, Admin controls them completely:

- **SHOW IN ALL CATEGORIES** adds a category to the directory.
- **HIDE FROM ALL CATEGORIES** removes it from the directory without deleting the collection.
- **DELETE** permanently removes the collection and it is not recreated on restart.
- **CREATE COLLECTION** lets Admin add new merchandise categories.
