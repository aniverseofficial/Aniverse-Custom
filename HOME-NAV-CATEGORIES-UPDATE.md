# Homepage / Navigation Update

- Removed New Arrivals and Pre-Orders product sections from homepage; they remain available through the navbar.
- Removed Best Sellers and Sale from desktop/mobile navbar.
- Added Banpresto Collection banner and dynamic Banpresto product rail, filtering products whose categories/name contain Banpresto.
- Added full-screen All Categories browsing page opened from the Categories dropdown's Shop All Categories action and mobile Shop All Categories action.
- Category directory is populated dynamically from `/api/categories` plus live product-derived category names, so admin category changes are reflected without frontend edits.
- Category cards open the existing catalogue surface for that category.
- Added responsive mobile styling for Banpresto banner and All Categories page.
